# 案E 第一次結果

環境・条件・しきい値は `README.md` を参照。数値はすべて追従誤差 rms（deg）の中央値（5 種）。
生データは `results/sweep.csv`、`results/sweep_summary.md`。

---

## 実験1：輸送遅延を掃引する（`DELAYS=0,50,100,200,400,800 SEEDS=5`）

| 遅延 | teacher | naive | P0 模倣・齢なし | P1 模倣・齢あり | P2 RL・齢なし | P3 RL・齢あり |
|---:|---:|---:|---:|---:|---:|---:|
| 0 ms | 0.092 | 3.433 | 0.644 | **0.378** | 0.248 | 0.265 |
| 50 ms | 0.092 | 4.894 | 0.945 | **0.769** | 0.795 | 0.727 |
| 100 ms | 0.092 | 6.325 | 1.595 | 1.436 | 1.725 | 1.858 |
| 200 ms | 0.092 | 9.045 | 3.286 | 3.059 | 3.114 | 3.233 |
| 400 ms | 0.092 | 13.727 | 7.333 | 8.929 | 6.634 | **6.456** |
| 800 ms | 0.092 | 19.100 | 15.938 | 15.860 | 12.381 | **13.533** |

対応のある比較（同じ種どうし。**中央値だけでは、ばらつきに埋もれた差を見分けられない**）:

| 遅延 | 齢の効果・模倣 P0→P1 | 齢の効果・RL P2→P3 | RL 対 模倣 P1→P3 |
|---:|---|---|---|
| 0 ms | **−41 %, 5/5** | +7 %, 0/5 | **−30 %, 5/5** |
| 50 ms | **−19 %, 5/5** | −9 %, 4/5 | −6 %, 3/5 |
| 100 ms | −10 %, 4/5 | +8 %, 2/5 | +29 %, 0/5 |
| 200 ms | −7 %, 4/5 | +4 %, 2/5 | +6 %, 2/5 |
| 400 ms | **+22 %, 1/5** | −3 %, 2/5 | **−28 %, 5/5** |
| 800 ms | −0.5 %, 3/5 | +9 %, 0/5 | **−15 %, 5/5** |

### 読み取り

1. **学習は明確に効く。** どの遅延でも naive（最後に知った目標をそのまま指令）を大きく下回る。
   800 ms でも 19.1 → 12.4 deg。ただし teacher（0.092 deg）には遠い。
2. **齢は、模倣では小さい遅延で効く。** 0 ms で −41 %（5/5）、50 ms で −19 %（5/5）。
   遅延が伸びるほど効果は薄れ、**400 ms では逆に悪化する（+22 %、勝ち 1/5）**。
3. **強化学習では齢の効果が検出できない。** 勝ち数は 0/5〜4/5 に散らばり、
   中央値の変化も ±9 % 以内で、種のばらつきに埋もれている。
4. **大遅延では強化学習が模倣を明確に上回る。** 400 ms で −28 %（5/5）、800 ms で −15 %（5/5）。
   これは案E の中心仮説 ——「**教師が失敗する領域は模倣では学べず、そこは強化学習が取る**」——
   を支持する唯一の、しかし明瞭な結果である。

### 事前に宣言した境界の扱い

- **$d^{*}_{IL}$ = 200 ms**（P1 の rms が宣言済みの `TOL=2.0 deg` を超える最小の遅延）。宣言どおり機能した。
- **$d^{*}_{RL}$ の定義は機能しなかった。** 「P3 が P1 を下回る最小の点」は 0 ms を返すが、
  100 ms と 200 ms では逆転しており**単調でない**ので、「境界」という言葉に値しない。
  \
  \prob 定義を後から都合よく変えない。ここでは事実を書くにとどめる ——
  **強化学習の優位は 400 ms 以上で 5/5 種と安定する**。
  次の実験では「$k$ 種すべてで下回る最小の点」という形で宣言し直して測る。

### この軸では仮説を検定できない（設計上の発見）

**遅延 $d$ は 1 回の走行のあいだ一定**である。したがって齢 $a$ は
「$d$（定数）＋ 配布周期 100 ms のなかの位相」であり、**情報として効くのは位相の部分だけ**で、
定数 $d$ は学習で重みに吸収される。位相の変動幅は $d$ によらず 100 ms で一定なので、
**「遅延が大きいほど齢が効く」はこの軸では原理的に出ない**。
実際、齢の効果は $d$ とともに薄れ、400 ms では入力がほぼ定数になったぶん
むしろ害になった（+22 %）と読める。

案E の主張は「**遅延が変動する条件下で**」である。したがって測るべき軸は
遅延の大きさではなく**遅延のばらつき**である。実験2 をそれに充てる。

## 実験2：遅延のばらつき（ジッタ）を掃引する（`DELAYS=100 JITTERS=0,25,50,100,200 SEEDS=5`）

ジッタは文脈の生成時刻に $\pm j$ の一様乱数として入る。追い越して着いた古い文脈は
**最新優先で捨てる**（案A の「文脈クラスは最新優先で上書き」に対応）。
これにより齢の変動幅は $j=0$ の 100 ms から $j=200$ ms では 279 ms へ広がり、
**齢が定数でなくなる**。

| ジッタ | teacher | naive | P0 模倣・齢なし | P1 模倣・齢あり | P2 RL・齢なし | P3 RL・齢あり |
|---:|---:|---:|---:|---:|---:|---:|
| 0 ms | 0.092 | 6.325 | 1.595 | **1.436** | 1.725 | 1.858 |
| 25 ms | 0.092 | 6.391 | 1.782 | **1.627** | 1.967 | 2.038 |
| 50 ms | 0.092 | 6.561 | 2.083 | **1.740** | 2.358 | 2.503 |
| 100 ms | 0.092 | 6.944 | 2.942 | **2.202** | 3.316 | 2.990 |
| 200 ms | 0.092 | 7.778 | 4.198 | **2.765** | 3.612 | 4.191 |

対応のある比較:

| ジッタ | 齢の効果・模倣 P0→P1 | 齢の効果・RL P2→P3 | naive 比の改善（P0 / P1） |
|---:|---|---|---|
| 0 ms | −10.0 %, 4/5 | +7.7 %, 2/5 | 75 % / 77 % |
| 25 ms | −8.7 %, 4/5 | +3.6 %, 1/5 | 72 % / 75 % |
| 50 ms | **−16.4 %, 5/5** | +6.2 %, 1/5 | 68 % / 73 % |
| 100 ms | **−25.1 %, 5/5** | −9.8 %, 3/5 | 58 % / 68 % |
| 200 ms | **−34.1 %, 5/5** | +16.0 %, 1/5 | 46 % / **64 %** |

### 読み取り

1. **予測1は的中**。齢の効果は −10 % → −34 % と**単調に強まり**、$j\ge50$ ms では **5 種すべて**で
   齢ありが勝つ。種ごとの差も −0.05 deg 級から −1.8 deg 級へ一桁大きくなる。
   **齢が効くのは遅延が大きいときではなく、遅延がばらつくときである。**
2. 齢は**劣化を食い止める**。naive 比の改善率は、齢なしが 75 % → 46 % と崩れるのに対し、
   齢ありは 77 % → 64 % にとどまる。
3. **予測3は外れ**、強化学習では今回も齢の効果が出ない（勝ち 1/5〜3/5、符号も一定しない）。
   実験1と合わせて **CEM が齢を使う解に届いていない**疑いが濃い。
4. **予測2は検定できなかった**。$a$ と $\hat a$ を同時に与えており分離していない。
   アブレーション（なし／$a$ のみ／$\hat a$ のみ／両方）が次の第一項目。

$d^{*}_{IL}$ = ジッタ 100 ms（宣言どおり機能）。$d^{*}_{RL}$ はこの軸では未到達。

## 計画書へ戻すべき修正

1. **掃引すべきは遅延の大きさではなく、ばらつき**。案D の「遅延を 0.1 ms から数百 ms まで
   変えた軌跡を生成する」は、固定遅延をいくら振っても齢の効果を測れない。
   分布の*位置*ではなく*形*を掃引する設計に直す。
2. **齢の効果の主戦場は大遅延ではなく高ジッタ**。案D の合格ラインもばらつきの関数で書く。
   実験2 の −34 %（±200 ms、5/5 種）が最初の目安になる。
