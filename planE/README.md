# 案E 第一次実験 —— 齢を状態に持つ方策は、模倣が届かない遅延領域を取れるか

`docs/ml_rt_proposals.pdf` 第8節（案E）の**着手ぶん**。機材を買う前に、
シミュレータだけで一次結果まで出すことを目的にした最小の実験系である。

## 問い

> 遅延を「情報として与えられた」方策は、遅延を「上界としてのみ扱う」方策より
> どれだけ良くなれるか。そして**模倣が原理的に届かなくなる領域**を、強化学習は取れるか。

案D は「齢が効く」ことを特権教師つき模倣学習で示す計画だが、
**教師自身が失敗する大遅延領域は模倣では学べない**と自ら範囲外を宣言している。
本実験はその境界を実際に測り、その先を強化学習が取れるかを見る。

## 6 条件（同じ軌道・同じ容量で比べる）

| 条件 | 制御 | 齢 $a$ と $\hat a$ |
|---|---|---|
| `teacher` | 遅延ゼロの理想制御（先行補償つき PD）。**性能の下界** | 本当の目標を知っている |
| `naive`   | 最後に知った目標角をそのまま指令。**学習なしの基準線** | 使わない |
| `P0` | 模倣学習（特権教師つき、DAgger 1 巡） | なし（端子はゼロ） |
| `P1` | 模倣学習 | **あり** |
| `P2` | 強化学習（CEM） | なし（端子はゼロ） |
| `P3` | 強化学習（CEM） | **あり** |

方策はすべて **121 パラメータ**（入力 8 → 隠れ 12 tanh → 出力 1）の残差方策で、
基底（= 最後に知った目標角）の上に ±40 deg の差分を出す。
1 kHz で回すこと、将来ノード上で固定小数点にすることを見込んだ規模である。

## 案E に固有の入力 —— $\hat a$（次の文脈が届くまでの残り時間）

案D が渡すのは「いま何 µs 古いか」（齢 $a$）だけである。本実験はもう 1 つ、
**「あと何 µs で新しい文脈が来るか」** を渡す。tickless ワンショットタイマは
次の起床時刻を持っているので、**OS だけが答えられる値**である。
方策から見れば未来の情報であり、「待つ」という行動を選べるかがこの 1 次元で変わる。
既存の遅延認識手法（DA-MDP、世界モデル、遅延ロバスト化）にはない入力である。

## 環境

- サーボ: 位置指令 → 内部 PD（ω=30 rad/s, ζ=1.0）、角速度飽和 `VMAX=180 deg/s`、可動域 0–180 deg、制御周期 1 ms。
- 上位目標: 0.15–0.8 Hz の滑らかな軌道（サーボ帯域より十分低いので、遅延ゼロなら誤差ほぼ 0 で追える＝教師が「正解」として機能する）。
- 文脈配布: 周期 100 ms（10 Hz）で生成され、輸送遅延 $d$ を経て届く。齢は $d$ から $d+100$ ms を鋸歯状に動く。
- 実物の VLA は使わない（案D の発想 —— **遅延の研究に、遅延を生む実物は要らない**）。

## しきい値は先に宣言してある

後から都合よく選ばないため、`sweep.py` の冒頭に固定してある。

- `TOL = 2.0 deg`（可動範囲 50 deg p-p の 4 %）
- $d^{*}_{IL}$ = P1 の rms が `TOL` を超える最小の遅延
- $d^{*}_{RL}$ = P3 の rms 中央値が P1 の rms 中央値を下回る最小の遅延

## 走らせ方

```sh
python3 test_planE.py                                   # 実験系そのものの検証（先に通す）
DELAYS=0,50,100,200,400,800 SEEDS=5 python3 sweep.py    # 本掃引 → results/
```

`results/sweep.csv` に全試行、`results/summary.md` に表と 2 つの境界が出る。
**指標は平均だけでなく p50/p90/p99/max を必ず出す**（集計値は嘘をつく）。

## 検証（`test_planE.py`、12 項目）

測っているものが「齢の効果」でなくなる壊れ方は 3 つある。機械的に検査している。

1. **容量が揃っていない** → 測っているのは容量差。4 条件のパラメータ数が同一（121）であることを検査。
   齢なし条件も**端子は持ったままゼロを流す**。
2. **齢マスクが効いていない** → 齢なし条件が齢を見てしまう。齢を変えても入力が不変であること、
   齢あり条件では出力が実際に変わること、齢の端子以外は同一であることを検査。
3. **学習と評価が同じ軌道** → 測っているのは過学習。学習は seed 2000 系列、評価は 1000 系列で分離。

ほかに、教師が遅延に依らず下界（rms < 0.2 deg）であること、naive が遅延とともに単調悪化すること、
齢の信号が実際に変動し輸送遅延以上であること、文脈走査の O(1) 実装が総当たりと一致することを検査する。

## 既知の限界（一次結果の読み方）

- **1 関節・剛体・摩擦なし**。バックラッシュ、静止摩擦、サーボの応答遅れは入っていない。
  実機微調整の段階で必ずずれる（案E の 2 年目の項目）。
- **`VMAX=180 deg/s` は推定値**でカタログ値ではない（`rl/dofbot_rl.py` と同じ仮定）。
  結論がこれに依存するなら感度解析が要る。
- **RL は CEM**（純 Python で回る規模に収めるため）。SAC 等との比較は未実施。
  学習量は模倣と強化学習で揃っていない（別アルゴリズムなので原理的に揃わない）ため、
  厳密な対照は **P0 対 P1** と **P2 対 P3** の 2 組であり、P1 対 P3 は境界の定義に使う。
- **齢は理想的に正確**。実機では OS の計時そのものに誤差がある。
  外部計測（ロジック・アナライザ）で裏を取る設計は案E の第 3 項目にある。
- メールボックス溢れによる文脈の欠落（`cc.c:532`）は `Context(p_drop=...)` に実装済みだが、
  本掃引では 0 にしてある（軸を増やすのは次段）。

## 次にやること

1. 落とし込み（`p_drop`）とジッタを軸に加える。$\hat a$ が外れる条件で何が起きるかが本題になる。
2. 「到達して止まる」課題（reach-and-stop）を足す。**「待つ」が最適になる**のはこちらで、
   追従課題より齢の効果が出やすいはずである。
3. 隣接関節（多関節・メッシュ経由の齢つき情報）へ拡大する。
4. 固定小数点・量子化した方策で同じ実験を回し、案F・案G の入力にする。
